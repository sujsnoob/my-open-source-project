# Архитектура проекта

## Общее описание

Task Manager — простой проект для демонстрации структуры Open Source приложения.

## Основные компоненты
- **Интерфейс:** взаимодействие с пользователем.
- **Менеджер задач:** добавление, просмотр и удаление задач.
- **Хранилище:** хранение списка задач.

## Принцип работы

Пользователь выполняет действие, менеджер задач обрабатывает запрос, а результат отображается пользователю.

## Развитие проекта

В дальнейшем можно добавить сохранение задач в файл и возможность устанавливать сроки выполнения.
